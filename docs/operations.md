# Работа с дашбордом

- На странице **Активные отправления** доступны оба кабинета и фильтр по каждому из них. Время обновления, начала обработки и отгрузки показано по Москве (MSK).
- Откройте номер отправления, чтобы посмотреть состав, артикулы, SKU, количество, цену, склад и способ доставки, если эти данные предоставил Ozon.
- Подтвердите сборку в кабинете Ozon. После следующего обновления отправление появится в колонке **Собраны — ждут отгрузки**. Нажмите **Печать этикетки**, дождитесь ссылки на PDF и распечатайте файл из браузера. Сервер хранит этикетку 24 часа.
- После печати нажмите **Отметить как напечатанную** на дашборде или в карточке отправления. Статус сохраняется между синхронизациями и после истечения срока хранения PDF. Флажок **Скрывать напечатанные** убирает отмеченные отправления из списка и из пакетной печати. Снимите флажок фильтра, чтобы снова увидеть карточки и при необходимости снять отметку.
- Флажок **Печатать название книги на этикетке** добавляет внизу PDF до двух строк шрифтом 7 pt. Длинное название обрезается. Если внизу нет свободного места, дашборд предложит открыть исходную этикетку.
- Кнопка **Печатать все этикетки** запрашивает PDF для всех собранных отправлений в текущем фильтре и открывает их одним файлом для печати. Флажок над кнопкой добавляет названия книг в комплект.
- Флажок **Сразу печатать через агент** отправляет одиночный или общий PDF в очередь CUPS на MacBook. Нативный агент передаёт файл командой `lp` без диалога. Статус «PDF передан в очередь» подтверждает приём задания принтером. После фактической печати отметьте её на карточке.
- Нажмите **PDF не загружен**, чтобы запросить этикетку без печати. Ссылка **PDF загружен** открывает готовый файл с учётом флажка печати. Если номер этикетки читается в PDF, он появится под номером отправления.
- Если агент не в сети, проверьте питание и интернет на ПК и состояние контейнера. Дашборд покажет последний успешно обновлённый список. После восстановления связи агент продолжит обработку.
- Если Ozon отклоняет доступ одного кабинета, проверьте его Client ID и права ключа. После замены ключа в локальном файле пересоздайте контейнер агента, чтобы он получил новые значения.

```bash
docker compose --env-file .env.agent -f compose.agent.yaml logs --tail=100 agent
docker compose --env-file .env.agent -f compose.agent.yaml up -d --force-recreate agent
```

Для обновления клона выполните `git pull --ff-only` и повторите команду запуска с `--build` для соответствующей машины.

## База данных

Создавайте резервные копии PostgreSQL на сервере. Сохраняйте их в закрытую папку. Данные отправлений входят в резервную копию базы, PDF из отдельного тома в неё не входят.

```bash
umask 077
docker compose --env-file .env.server -f compose.server.yaml exec -T database \
  pg_dump -U dashboard -Fc dashboard > dashboard.dump
```

Храните резервную копию отдельно от Git. При обычном перезапуске Compose использует существующий том базы. Для ротации секрета агента обновите его на сервере и на ПК, затем пересоздайте оба контейнера.
