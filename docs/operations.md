# Работа с заказами

- На странице «Активные отправления» можно переключать кабинеты, скрывать напечатанные отправления и открывать карточку заказа по его номеру.
- «Собрать» и «Собрать и напечатать» запускают фоновые задания. Панель внизу показывает ход и результат по каждому заказу. После подтверждения сборки список обновляется без перезагрузки.
- «Напечатать» отправляет этикетку в очередь macOS. Флажок «Сразу печатать через агент» также включает прямую печать для открываемых PDF и пакетной печати. Без флажка PDF открывается в панели предпросмотра. Кнопка «PDF не загружен» только запрашивает этикетку.
- При печати через агент название книги добавляется для Ozon и по флажку для Wildberries. Если название не помещается, агент печатает исходную этикетку, а результат содержит номер этикетки и название книги. Если номер этикетки недоступен, показывается номер отправления.
- Для ручной печати через агент отметка появляется после приёма задания очередью. Для автоматической печати в журнале мониторинга нажмите «Упаковано» после фактической упаковки. Если результат отправки неизвестен, сверьтесь с очередью принтера перед повтором.
- Мониторинг включается на дашборде или на странице «Мониторинг». Он продолжает работать при закрытом браузере, пока локальные сервисы и агент запущены. Начало новой смены выключает мониторинг.
- Если агент перестал отвечать, проверьте `data/macos-agent.log`, доступ к маркетплейсам и очередь принтера. [Команды запуска и обслуживания](macos.md).
