# Обложки в журнале печати

В колонке «Название книги» показываются миниатюры, которые увеличиваются при наведении или фокусе.

Чтение только из активных отправлений оставило бы журнал без фото после их выгрузки. Поэтому сохраняем ссылки в записи печати; для старых записей используем обложки активного отправления, если они доступны. Если фото нет, остаётся название. Печать и подтверждение не меняются.
