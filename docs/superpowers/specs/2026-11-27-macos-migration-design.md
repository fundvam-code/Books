# Переезд дашборда на macOS

На Mac работают PostgreSQL 16, веб-приложение и Caddy в Docker Desktop, а нативный агент обращается к API площадок и печатает через CUPS. Дашборд доступен с самого Mac по HTTPS через 127.0.0.1. Сохраняются браузерная авторизация, отдельный токен агента и проверка Origin. Caddy подписывает сертификат локальным CA. Агент доверяет этому CA только при подключении к дашборду.

Нативная установка PostgreSQL, Python-приложения и прокси тоже возможна. Выбран Compose, чтобы сохранить версию PostgreSQL, зависимости приложения, шрифты этикеток и схему томов при переходе с сервера на Mac. Агент остаётся нативным для доступа к принтеру. Постоянный запуск агента обеспечивает пользовательский LaunchAgent после входа в macOS.

Данные переносятся логическим дампом базы и архивом тома этикеток. Первая копия служит для репетиции с изолированным проектом Compose и выключенным агентом. Согласованная финальная копия требует короткой паузы записи на старой стороне. До переключения действующий сервер и агент продолжают работу. После начала записи на Mac откат требует переноса актуальных базы и этикеток обратно. Запись и обработка заказов активны только в одном экземпляре.

Ключи Ozon и Wildberries остаются в локальных файлах агента. Git содержит код, шаблоны без значений и инструкции. Mac по-прежнему требует доступ к Seller API и, при использовании каталога мест хранения, к Google Sheets.
