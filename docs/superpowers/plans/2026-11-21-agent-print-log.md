# Журнал печати через агент

Ссылка внизу дашборда открывает журнал подтверждённых заданий печати. Для каждой этикетки сохраняются кабинет, название книги, номер отправления, номер этикетки и время по Москве.

- [x] Записывать результат `submitted` в одной транзакции с завершением печати. Сохранять записи отдельно от временных PDF и заданий.
- [x] Перенести сохранившиеся задания с результатом `submitted`. Для них показывать время создания задания.
- [x] Добавить страницу журнала и проверить подтверждение, отказ, ручную отметку, повтор запроса и очистку временных заданий.
