# Перевод задания Wildberries на сборку

- Добавить страницу подтверждения для нового задания. Пользователь выбирает ID открытой поставки и подтверждает действие.
- Через существующую очередь выдать действие только агенту, объявившему поддержку записи WB. Агент использует локальный `WB_WRITE_TOKEN` категории «Маркетплейс» с правом «Чтение и запись».
- Перед обновлением проверить открытую поставку и актуальный статус задания. Зафиксировать начало внешней записи и исключить автоматический повтор при неопределённом результате.
- Проверить перенесение, запреты, права и обработку незавершённого запроса на имитации API. На рабочем сервере проверить страницы без перевода реальных заказов.
