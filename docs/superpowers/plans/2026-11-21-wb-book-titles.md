# Названия книг на этикетках Wildberries

Использовать название из каталога WB по артикулу товара. Сопоставлять числовые и строковые артикулы и показывать состояние загрузки каталога в дашборде.

Переиспользовать галочку названия для одиночной и групповой печати. Для WB пропорционально уменьшать исходное содержимое и размещать под ним не более двух строк шрифтом 7 pt. Сохранять физический размер страницы и состав маркировки.

- [x] Проверить PDF с названием в одиночной и групповой печати и совместимость с Ozon.
