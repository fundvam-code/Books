# Wildberries FBS Implementation Plan

Подключить один кабинет Wildberries FBS к действующему дашборду. Агент получает задания, статусы и стикеры WB. Сервер обрабатывает данные и готовит PDF. В дашборде доступны открытие и групповая печать стикеров, номер стикера и ручная отметка о печати. Доступ к карточкам товаров для названий книг настраивается отдельно.

- [x] Добавить клиент WB и чтение необязательного файла `.env.wb` в Docker и на MacBook. Проверить пагинацию, статусы и ограничение запросов.
- [x] Регистрировать кабинет WB по сигналу агента и выдавать его задания агенту с настроенным кабинетом. Сохранить совместимость с агентом Ozon, который запрашивает задания без тела запроса.
- [x] Подключить стикеры через существующую очередь и преобразовать PNG в PDF 58×40 мм на сервере. Использовать номер из ответа WB. Проверить предусловия публикации, вывод в дашборде и групповую печать на имитации принтера.
- [x] Проверить совместимость со схемой PostgreSQL, запросы WB на имитации API, раздельные статусы и фильтр напечатанного. Обновить инструкции для агента.
