# Открытие диалога печати этикеток

- Открывать формы одиночной и пакетной печати в отдельном окне. Вызывать печать по флажку и сохранять его состояние, пока агент готовит PDF.
- Открывать PDF непосредственно в просмотрщике и добавлять действие Print в режиме автопечати.
- Проверить формирование PDF в двух режимах, сохранение размеров и выполнение действия Print в PDFium.
