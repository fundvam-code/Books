# Печать PDF через локальный агент

- Создавать запрос на печать только по явно выбранному флажку. Для одиночной и пакетной печати дождаться PDF и передать его агенту.
- Нативный агент на macOS забирает PDF, резервирует отправку и передаёт байты в очередь CUPS через lp. При неопределённом результате повтор автоматически не выполняется.
- Проверить захват задания, отправку исходных байтов, отсутствие повторной отправки и совместимость с агентом в Docker.
