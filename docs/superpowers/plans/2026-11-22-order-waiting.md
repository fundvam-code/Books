# Отправления в ожидании

- Хранить отметку ожидания в дашборде. Переносить готовое к печати отправление в отдельный список и сохранять его при обновлении заказов. При начале смены очищать список.
- Добавить кнопку переноса, кнопку возврата и галочку «Скрывать ожидающие» для основных колонок. По умолчанию скрывать ожидающие из очереди отгрузки.
- Исключать отложенные отправления из счётчиков и печати до возврата. Проверить обе площадки, групповую печать, обновление заказов и сброс смены на отдельной базе.
