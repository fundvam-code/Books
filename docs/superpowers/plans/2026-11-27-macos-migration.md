# macOS Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Подготовить полный запуск сервиса и перенос накопленных данных на Mac.
**Architecture:** Серверный Compose дополняется локальной конфигурацией Caddy. Нативный агент доверяет локальному CA и использует CUPS. Дамп и архив PDF переносятся вместе.
**Tech Stack:** Docker Desktop, Compose, Caddy, PostgreSQL 16, Python, launchd.
**Spec:** [Дизайн](../specs/2026-11-27-macos-migration-design.md)

## Global Constraints

- Интерфейс публикуется только на 127.0.0.1. Агент и браузер проверяют HTTPS.
- Действующий сервер и агент продолжают работать во время подготовки и репетиции.
- Ключи, настройки с секретами и рабочие данные передаются отдельно от Git.

## Review Focus

- Слияние Compose не должно сохранять публичные порты рабочего сервера.
- Локальный CA должен применяться только к HTTP-клиенту дашборда.
- Проверка резервной копии учитывает неполную выгрузку и повторный импорт в занятый проект.
- Параллельные задания сборки и печати предотвращаются выключенным агентом репетиции и переключением одного источника записи.
