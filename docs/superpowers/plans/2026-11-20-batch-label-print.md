# Печать этикеток пачкой

- Добавить кнопку печати для готовых к отгрузке отправлений в текущем фильтре.
- Запрашивать отсутствующие PDF через существующую очередь и повторно использовать готовые.
- После готовности всех файлов открыть единый PDF с исходными размерами страниц. Если часть файлов недоступна, показать причину и дать повторить запрос.
- Проверить выбор одного и обоих кабинетов, ожидание, ошибку агента и объединение PDF.
