# Начало смены

Кнопка внизу дашборда открывает подтверждение сброса. Сброс очищает текущие отправления, отметки и журнал печати, ошибки синхронизации и прежние задания. Затем каждый кабинет получает новое задание на загрузку.

- [x] Выполнять сброс одной транзакцией и согласовать его с операциями агента. Блокировать сброс во время активной отправки PDF в очередь принтера. Повторное подтверждение одной смены не должно очищать новые данные.
- [x] Добавить страницу подтверждения и автоматически обновлять список в первые минуты после запуска загрузки.
- [x] На отдельной базе проверить очистку, повторную синхронизацию, защиту от устаревших ответов агента и отказ без подтверждения.
- [x] Обновлять счётчики вкладок дашборда и заголовок браузера через отдельный запрос без перезагрузки страницы.
