# Работа с GitHub

- Для обновлений репозитория `fundvam-code/Books` сначала используй `gh` или обычный `git`. Для получения изменений подходят `git fetch` и `git pull`. Для публикации используй `git push` или команды `gh`, включая `gh api`.
- Если команда не сработала, проверь причину и попробуй другой из этих двух способов, если он подходит. Встроенные инструменты GitHub используй только когда через `gh` и `git` выполнить операцию не удалось.
