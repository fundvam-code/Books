# Локальный дашборд заказов FBS

Дашборд объединяет два кабинета Ozon и один кабинет Wildberries. На одном Mac работают веб-приложение, PostgreSQL и Caddy в Docker Desktop и нативный агент macOS. Агент обращается к API маркетплейсов и отправляет этикетки в очередь принтера macOS.

Интерфейс доступен на этом Mac по адресу `https://127.0.0.1:8443/orders`.
