# Дашборд заказов Ozon FBS

Активные отправления двух кабинетов Ozon, карточки товаров и печать официальных этикеток со штрихкодом. Сервер хранит данные в PostgreSQL и показывает их в браузере. Агент на вашем ПК загружает данные из Seller API по исходящему соединению и читает ключи из локального файла окружения.

1. На сервере разверните веб-приложение, PostgreSQL и Caddy через `compose.server.yaml`.
2. На ПК с доступом к Ozon запустите агент через `compose.agent.yaml`.
3. Откройте дашборд по HTTPS. Для собранного отправления нажмите «Печать этикетки» и откройте PDF в браузере.
