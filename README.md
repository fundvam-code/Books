# Дашборд заказов FBS

Активные отправления двух кабинетов Ozon и одного кабинета Wildberries, карточки товаров и печать официальных этикеток со штрихкодом. Сервер хранит данные в PostgreSQL и показывает их в браузере. Агент на вашем ПК загружает данные из API площадок по исходящему соединению и читает ключи из локальных файлов окружения.

1. На сервере разверните веб-приложение, PostgreSQL и Caddy через `compose.server.yaml`.
2. Запустите агент на компьютере с доступом к API площадок. Для Wildberries добавьте [токен в локальный файл `.env.wb`](docs/deploy.md#подключение-wildberries). Для прямой печати без диалога используйте [нативный запуск на MacBook](docs/deploy.md#прямая-печать-на-macbook). Для загрузки заказов через Docker используйте `compose.agent.yaml`.
3. Откройте дашборд по HTTPS. Для собранного отправления нажмите «Печать этикетки» и откройте PDF в браузере.
