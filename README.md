# Дашборд заказов Ozon FBS

Локальный планировщик заказов Ozon FBS: сервер работает в Docker, а локальный агент на компьютере обращается к Seller API через его интернет-подключение.

На этом этапе репозиторий содержит одобренный дизайн и план реализации. Ключи API, файлы `.env` и полученные этикетки не добавляются в Git.
